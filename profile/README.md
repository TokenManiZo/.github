## 👋 About Us

**TokenManiZo(TMZ)**는 화이트햇스쿨 4기에서 결성된 웹·API 보안 프로젝트 팀입니다.

기존 웹 API 보안 점검에서 복잡한 요청 흐름과 접근통제 관계를 분석자가 직접 파악해야 하는 한계에 주목하여, **API 탐색 결과를 통합하고 신원–API–객체 간의 관계를 시각화하는 FlowScope**를 개발했습니다.

프로젝트를 통해 개발한 기술을 오픈소스 취약점 연구와 실제 블랙박스 버그바운티에 적용하고, API 인가 취약점 분석 방법론에 관한 학술 연구를 수행했습니다.

## 🚀 Project

### 🔍 FlowScope

**Burp Suite 기반 웹·API 탐색 및 접근통제 분석 도구**

FlowScope는 수동 점검, OWASP ZAP, LLM 기반 탐색에서 수집한 API 트래픽을 통합하여 탐색 범위의 차이와 접근통제 관계를 분석하는 도구입니다.

복잡한 API 호출 흐름을 관계 그래프로 시각화하고, 실제 HTTP 요청·응답을 기반으로 인가 취약점 후보의 분석과 검증을 지원합니다.

**Key Features**

- **API Discovery** — 다양한 출처의 API 탐색 결과 수집 및 정규화
- **Coverage Gap Analysis** — Human·Scanner·LLM 간 탐색 범위 비교 및 미점검 영역 식별
- **Identity–API–Object Graph** — 신원·API·객체 간 관계 시각화
- **Authorization Matrix** — 계정·역할·객체 소유 관계 기반 접근통제 분석
- **Cross-Identity Verification** — 계정별 접근 결과 비교 및 IDOR·BOLA·BFLA 취약점 후보 검증 지원
- **Evidence-based Analysis** — HTTP 요청·응답 기반 분석 근거 제공
